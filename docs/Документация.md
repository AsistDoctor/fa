# Документация: 3D Floor Plan Viewer

## Общее описание

3D Floor Plan Viewer — это веб-приложение на основе WebGL для визуализации и позиционирования 3D моделей зданий на интерактивном плане этажа. Приложение позволяет загружать несколько 3D моделей в формате OBJ, размещать их на плане, вращать и экспортировать их позиции.

---

## Архитектура приложения

### Основные компоненты

1. **HTML структура** (`index.html`)
   - Canvas элемент для WebGL рендеринга
   - Панель управления (HUD) с кнопками и подсказками

2. **JavaScript логика** (`main.js`)
   - WebGL шейдеры (вершинный и фрагментный)
   - Загрузка и парсинг OBJ файлов
   - Система управления камерой
   - Система позиционирования моделей
   - Рендеринг сцены

3. **Стили** (`styles.css`)
   - Оформление интерфейса

## Технические детали

### WebGL рендеринг

Приложение использует WebGL для отрисовки 3D сцены:

- **Вершинный шейдер** обрабатывает позиции вершин, нормали, цвета и UV координаты
- **Фрагментный шейдер** вычисляет освещение и применяет текстуры
- Используется система матриц для преобразований (проекция, вид, модель)

### Загрузка моделей

1. **Парсинг OBJ файлов**
   - Чтение вершин (v)
   - Чтение нормалей (vn)
   - Парсинг граней (f) с поддержкой различных форматов индексации
   - Автоматическое определение системы индексации (0-based или 1-based)

2. **Обработка моделей**
   - Вычисление границ модели (bounding box)
   - Центрирование модели
   - Масштабирование под размер плана
   - Выравнивание по полу с заданным зазором

3. **Нормализация высоты**
   - После загрузки всех моделей находится максимальная высота
   - Все модели масштабируются по оси Y до этой максимальной высоты
   - Масштабирование происходит относительно центра модели

### Система камеры

Камера использует орбитальную модель:

- **target** — точка, на которую направлена камера
- **distance** — расстояние от target до камеры
- **yaw** — горизонтальный угол поворота
- **pitch** — вертикальный угол наклона

**Ограничения:**
- Минимальное расстояние: 60 единиц
- Максимальное расстояние: 2000 единиц
- Угол pitch: от 0.2 до 2.2 радиан

### Позиционирование моделей

Каждая модель имеет:

- **offset** — смещение по осям X, Y, Z
- **rotation** — поворот вокруг оси Y (yaw)
- **basePositions** — исходные позиции вершин
- **baseCenters** — центр модели

При изменении позиции или поворота применяется трансформация:
1. Вершины переводятся относительно центра модели
2. Применяется поворот вокруг оси Y
3. Применяется смещение (offset)
4. Обновляется GPU буфер для отрисовки

## Функциональность

### Управление камерой

**Мышь:**
- Перетаскивание — вращение камеры вокруг target
- Колёсико — приближение/отдаление

**Клавиатура:**
- **Стрелки/WASD** — движение камеры по горизонтали
- **Space/PageUp** — движение камеры вверх
- **Shift/PageDown** — движение камеры вниз
- **R** — сброс позиции камеры к начальной

### Управление моделями

**Выбор модели:**
- Клавиши **1-7** — выбор активной модели

**Вращение:**
- **Q** — вращение против часовой стрелки
- **E** — вращение по часовой стрелке
- Работает всегда, когда выбрана модель

**Позиционирование (Position Mode):**
- Включается/выключается кнопкой "Position Mode"
- **Стрелки** — перемещение модели по горизонтали
- **Q/E** — быстрое вращение модели
- **PageUp/PageDown** — перемещение модели вверх/вниз

### Экспорт данных

1. **Export to OBJ** — экспортирует активную модель в формат OBJ
2. **Export Positions** — сохраняет все позиции и повороты моделей в JSON файл

### Загрузка позиций

При загрузке страницы автоматически загружается файл `model_positions.json`:
- Применяются сохранённые позиции моделей
- Применяются сохранённые повороты
- Модели перемещаются в указанные позиции

## Структура данных

### model_positions.json

```json
{
  "model1": {
    "offset": { "x": 1650, "y": 0, "z": -539 },
    "rotation": { "yaw": 0 },
    "file": "models/11111.obj"
  },
  ...
}
```

### Внутренние структуры

**Камера:**
```javascript
{
  target: [x, y, z],
  distance: number,
  yaw: number,
  pitch: number
}
```

**Модель:**
```javascript
{
  positions: Float32Array,  // x, y, z для каждой вершины
  normals: Float32Array,    // nx, ny, nz для каждой вершины
  colors: Float32Array,     // r, g, b для каждой вершины
  uvs: Float32Array         // u, v для каждой вершины
}
```

## Алгоритмы

### Загрузка OBJ модели

1. Загрузка текстового файла через fetch
2. Парсинг строк:
   - `v x y z` → вершина
   - `vn x y z` → нормаль
   - `f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3` → грань
3. Определение системы индексации
4. Вычисление границ модели
5. Центрирование и масштабирование
6. Создание треугольников из граней
7. Вычисление нормалей для треугольников (если не указаны)

### Нормализация высоты

1. После загрузки всех моделей вычисляется высота каждой
2. Находится максимальная высота
3. Для каждой модели:
   - Вычисляется коэффициент масштабирования: `scaleY = maxHeight / currentHeight`
   - Все вершины масштабируются по Y относительно центра модели
   - Обновляются базовые позиции и центры
   - Применяется трансформация

### Рендеринг

1. Обновление движения камеры (если нажаты клавиши)
2. Обновление вращения моделей (если нажаты Q/E)
3. Очистка буферов
4. Вычисление матриц проекции и вида
5. Установка uniform переменных (свет, текстуры)
6. Отрисовка пола (если включен)
7. Отрисовка сетки (если включен план)
8. Отрисовка всех моделей
9. Отрисовка стен и комнат (если есть)
10. Запрос следующего кадра через `requestAnimationFrame`

## Константы и настройки

### Размеры

- `PLAN_SIZE = 1100` — базовый размер плана (увеличен в 5 раз)
- `PLAN_TEXTURE_SIZE = PLAN_SIZE * 1.35` — размер текстуры плана
- `GRID_CELL_SIZE = 100` — размер ячейки сетки (увеличен пропорционально)

### Скорости

- `POSITION_STEP = PLAN_SIZE * 0.01` — шаг перемещения модели
- `ROTATION_STEP = Math.PI / 36` — шаг поворота (5 градусов)
- Скорость движения камеры: 5.0 единиц за кадр
- Скорость вращения модели: `ROTATION_STEP * 0.5` при удержании клавиш

### Ограничения

- Дальность обзора (far plane): 10000 единиц
- Минимальное расстояние камеры: 60 единиц
- Максимальное расстояние камеры: 2000 единиц
- Угол pitch: от 0.2 до 2.2 радиан

## Обработка ошибок

Приложение включает обработку ошибок:

1. **WebGL контекст** — проверка доступности и потери контекста
2. **Загрузка моделей** — обработка ошибок парсинга OBJ
3. **Рендеринг** — try-catch блоки для предотвращения падений
4. **Глобальные ошибки** — перехват необработанных ошибок для предотвращения перезагрузки страницы

## Производительность

### Оптимизации

- Использование VAO (Vertex Array Objects) для ускорения отрисовки
- Статические буферы для неизменяемых данных
- Обновление GPU буферов только при изменении модели
- Проверка валидности данных перед отрисовкой

### Ограничения

- Максимальное количество моделей: 8
- Размер моделей ограничен дальностью обзора
- Производительность зависит от сложности моделей (количества треугольников)

## Расширяемость

### Добавление новых моделей

1. Поместить OBJ файл в папку `models/`
2. Добавить путь в массив `modelFiles`
3. Убедиться, что есть достаточно мешей в `buildingMeshes`

### Изменение настроек

- Размер плана: изменить `PLAN_SIZE`
- Размер сетки: изменить `GRID_CELL_SIZE`
- Скорости: изменить соответствующие константы
- Цвета: изменить значения в массивах цветов

## Использование

### Запуск

1. Установить Python 3
2. Запустить сервер: `python start_server.py`
3. Открыть браузер: http://localhost:3000

### Рабочий процесс

1. Загрузить модели (автоматически при открытии)
2. Выбрать модель клавишами 1-7
3. Включить Position Mode для позиционирования
4. Переместить и повернуть модель
5. Экспортировать позиции для сохранения
6. При следующем открытии позиции загрузятся автоматически
