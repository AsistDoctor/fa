# Пользовательская документация

## 1. Назначение

Система предназначена для интерактивной 3D-визуализации университетского кампуса:
- просмотр корпусов;
- навигация по сцене;
- просмотр этажей;
- добавление/редактирование меток;
- dev-настройка положения корпусов.

## 2. Основные функции

- Загрузка 3D-моделей корпусов.
- Панорамная навигация камерой (мышь/клавиатура/touch).
- Режим позиционирования моделей (перемещение, поворот, масштаб).
- Система этажей (кнопки `-`, `+`, `Все`).
- Система меток (добавление, редактирование, список).
- Экран загрузки с прогресс-баром.
- Освещение "день/ночь" (солнце и луна в реальном времени).
- SEO-готовность (meta, OG, twitter, sitemap, robots).

## 3. Управление

### Камера
- Мышь: вращение.
- Колесо: приближение/отдаление.
- `W/A/S/D` или стрелки: движение в плоскости.
- `Space` / `Shift`: движение вверх/вниз.

### Модели (DEV)
- `1..9`: выбор активной модели.
- `Q/E`: поворот активной модели.
- `Position Mode`:
  - стрелки: смещение по `X/Z`;
  - `PageUp/PageDown`: смещение по `Y`.
- Ползунки `X/Y/Z`: масштаб по осям.

### Этажи
- `-` / `+`: изменение выбранного этажа.
- `Все`: показать все этажи корпуса.

### Метки
- `Add Label Mode`: создание метки кликом по сцене/модели.
- `Show Labels`: открыть список меток.
- В модальном окне: текст, цвета, размер, смещение, привязка к модели.

## 4. Запуск приложения

```bash
python server.py
```

- Локально: `http://localhost:3000`
- В локальной сети: `http://<LAN_IP>:3000`

## 5. Хранение данных

- Базовые позиции: `model_positions.json`.
- DEV API хранит трансформы в `SQLite` (`dev_data.sqlite3`).
- Метки: `labels.json` + fallback в `localStorage`.

## 6. Ограничения текущей версии

- Основной формат моделей: `OBJ` (рекомендуется перейти на `GLB`).
- Интерьеры этажей как отдельные модели пока не интегрированы.
- DEV endpoints должны быть отключены перед production.

## 7. Практический сценарий использования

1. Открыть систему в браузере.
2. Проверить загрузку корпусов и общий план.
3. Включить `Position Mode` и откорректировать положение корпуса.
4. Проверить этажи для выбранного корпуса.
5. Добавить и отредактировать метки.
6. Сохранить/экспортировать данные при необходимости.
