# Документация проекта: 3D Карта Кампуса

Этот каталог содержит документацию для дипломного проекта и разработки.

## Файлы документации

- `Документация.md` — пользовательская документация (сценарии работы, управление).
- `Техническая_Документация.md` — техническая документация (архитектура, модули, API, данные).

## Кратко о проекте

Веб-приложение на Three.js для визуализации кампуса:
- 3D-модели корпусов;
- управление камерой и сценой;
- система этажей;
- метки (labels);
- dev-позиционирование моделей;
- динамическое освещение (солнце/луна);
- SEO-оптимизация;
- dev API + SQLite для реактивного сохранения позиций.

## Запуск

```bash
python server.py
```

- Локально: `http://localhost:3000`
- По LAN: `http://<ваш_LAN_IP>:3000`

## Примечания

- В dev-режиме позиции моделей сохраняются через API в `dev_data.sqlite3`.
- При отключенном dev API используется fallback на `model_positions.json`.
- Для production рекомендуется отключить dev-endpoints.
