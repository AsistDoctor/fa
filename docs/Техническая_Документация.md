## Обзор приложения

**3D Floor Plan Viewer** — веб-приложение для визуализации и редактирования 3D-планов зданий в браузере. Приложение позволяет:

- Загружать и отображать несколько 3D-моделей одновременно
- Позиционировать и масштабировать модели в 3D-пространстве
- Добавлять интерактивные метки к моделям и сцене
- Управлять камерой для навигации по сцене
- Экспортировать и импортировать позиции моделей и меток

- **Three.js v0.169.0** — библиотека для 3D-графики

## Система меток (Labels)

### Обзор

Система меток позволяет добавлять интерактивные HTML-элементы в 3D-пространство. Метки автоматически следуют за моделями при их перемещении и могут быть привязаны к конкретным моделям или размещены в произвольных точках сцены.

### Основные возможности

1. **Создание меток**
   - Клик по модели или сцене в режиме "Add Label Mode"
   - Автоматическое позиционирование над моделью
   - Настройка текста, цветов, размера шрифта

2. **Редактирование меток**
   - Клик по метке для открытия редактора
   - Изменение текста, цветов, размера
   - Настройка высоты над объектом
   - Привязка/отвязка от модели

3. **Управление метками**
   - Панель со списком всех меток
   - Быстрое редактирование и удаление
   - Автоматическое сохранение в localStorage

4. **Сохранение и загрузка**
   - Метки сохраняются в `model_positions.json` вместе с моделями
   - Автоматическая загрузка при старте приложения
   - Синхронизация с localStorage

### Структура данных метки

```json
{
  "labels": {
    "label_1234567890_abc123": {
      "text": "Название метки",
      "position": {
        "x": 100.0,
        "y": 50.0,
        "z": -200.0
      },
      "modelIndex": 1,
      "backgroundColor": "rgba(74, 158, 255, 0.9)",
      "color": "#ffffff",
      "fontSize": "14px",
      "offsetY": 30
    }
  }
}
```

### Функции работы с метками

#### `createLabel(text, object, options)`

Создает HTML метку в 3D пространстве.

**Параметры:**
- `text` (string) — текст метки
- `object` (THREE.Object3D) — объект, к которому привязана метка
- `options` (object) — опции стилизации:
  - `backgroundColor` — цвет фона (по умолчанию: `rgba(0, 0, 0, 0.7)`)
  - `color` — цвет текста (по умолчанию: `#fff`)
  - `fontSize` — размер шрифта (по умолчанию: `14px`)
  - `offset` — смещение метки `{x, y, z}` (по умолчанию: `{0, 1, 0}`)

**Возвращает:** `THREE.CSS2DObject` — объект метки

#### `createNewLabel(position, modelIndex)`

Создает новую метку в указанной позиции.

**Параметры:**
- `position` (THREE.Vector3) — позиция метки в 3D пространстве
- `modelIndex` (number|null) — индекс модели для привязки (1-9) или `null`

**Возвращает:** `THREE.CSS2DObject` — объект метки

#### `updateLabel(labelId, data)`

Обновляет текст и стили существующей метки.

**Параметры:**
- `labelId` (string) — уникальный идентификатор метки
- `data` (object) — данные для обновления:
  - `text` — новый текст
  - `backgroundColor` — новый цвет фона
  - `color` — новый цвет текста
  - `fontSize` — новый размер шрифта
  - `offsetY` — новая высота над объектом

#### `deleteLabel(labelId)`

Удаляет метку из сцены и из массива меток.

**Параметры:**
- `labelId` (string) — уникальный идентификатор метки

#### `updateLabelsPanel()`

Обновляет панель со списком всех меток.

#### `saveLabelsToJSON()`

Сохраняет метки в localStorage (без автоматического скачивания файла).

#### `loadLabelsFromJSON()`

Загружает метки из `model_positions.json` или localStorage.

**Алгоритм загрузки:**
1. Пытается загрузить из `model_positions.json` (секция `labels`)
2. Если файл не найден или секция отсутствует, загружает из localStorage
3. Создает метки в сцене с сохраненными параметрами

### Режим добавления меток

**Включение:** Кнопка "Add Label Mode: On"

**Поведение:**
- Курсор меняется на крестик
- Управление камерой отключается (`controls.enabled = false`)
- Клик по модели создает метку, привязанную к модели
- Клик по пустому месту создает свободную метку
- Клик по UI элементам игнорируется

**Выключение:** Повторное нажатие кнопки

## Управление моделями

### Загрузка моделей

Модели загружаются из папки `models/` с использованием `OBJLoader`. Список моделей определяется в массиве `modelFiles`:

```javascript
const modelFiles = [
  "models/11111.obj",
  "models/2к 3D.obj",
  "models/3к 3D.obj",
  "models/4к 3D.obj",
  "models/5к.obj",
  "models/6к.obj",
  "models/7к.obj",
  "models/highway road.obj",
  "models/blueCorp.obj"
];
```

### Обработка моделей при загрузке

1. **Парсинг OBJ файла** — извлечение вершин, нормалей, граней
2. **Вычисление границ** — определение размеров модели
3. **Масштабирование** — подгонка под размер плана (90% от `PLAN_SIZE`)
4. **Центрирование** — выравнивание центра модели
5. **Выравнивание по полу** — поднятие модели над планом
6. **Вычисление нормалей** — если нормали отсутствуют в файле
7. **Применение материала** — настройка цвета и свойств материала

### Позиционирование моделей

#### Режим позиционирования (Position Mode)

**Включение:** Кнопка "Position Mode: On"

**Управление:**
- **Стрелки вверх/вниз** — перемещение по оси Z
- **Стрелки влево/вправо** — перемещение по оси X
- **Space/PageUp** — поднять модель (ось Y)
- **Shift/PageDown** — опустить модель (ось Y)
- **Q** — поворот против часовой стрелки
- **E** — поворот по часовой стрелке
- **1-9** — выбор активной модели

#### Масштабирование моделей

Ползунки в панели управления позволяют масштабировать активную модель по осям X, Y, Z:

- Диапазон: 10% - 300% от исходного размера
- Масштабирование относительно центра модели
- Автоматическое обновление позиции для сохранения визуального положения

### Структура данных модели в JSON

```json
{
  "model1": {
    "offset": {
      "x": 1716,
      "y": -454.64,
      "z": -539
    },
    "rotation": {
      "yaw": 0
    },
    "scale": {
      "x": 1.0,
      "y": 1.0,
      "z": 1.0
    },
    "file": "models/11111.obj"
  }
}
```

**Примечание:** Масштаб сохраняется как относительные значения (1.0 = 100%).

## Система камеры

### Тип камеры

`THREE.PerspectiveCamera` с параметрами:
- **FOV:** 55 градусов
- **Aspect:** Соотношение сторон окна
- **Near:** 0.1 единиц
- **Far:** 10000 единиц

### Управление камерой

#### OrbitControls

Автоматическое управление через `OrbitControls`:
- **Перетаскивание мыши** — вращение камеры вокруг цели
- **Колёсико мыши** — приближение/отдаление
- **Ограничения:**
  - Минимальное расстояние: 60 единиц
  - Максимальное расстояние: 2000 единиц
  - Минимальный угол наклона: 0.2 радиан
  - Максимальный угол наклона: 1.88 радиан (π * 0.6)

#### Клавиатурное управление

**В обычном режиме:**
- **WASD / Стрелки** — движение камеры по горизонтали
- **Space / PageUp** — движение камеры вверх
- **Shift / PageDown** — движение камеры вниз
- **R** — сброс камеры к начальной позиции

**Скорость движения:** 5.0 единиц за кадр

**В режиме добавления меток:**
- Управление камерой полностью отключается
- Движение камеры блокируется

### Начальная позиция камеры

```javascript
camera.position.set(0, 480, 480);
camera.lookAt(0, 2, -10);
```

## Загрузка и сохранение данных

### Структура model_positions.json

Файл содержит позиции моделей и меток:

```json
{
  "model1": {
    "offset": {...},
    "rotation": {...},
    "scale": {...},
    "file": "..."
  },
  "model2": {...},
  ...
  "labels": {
    "label_123": {...},
    "label_456": {...}
  }
}
```

### Загрузка данных

**Автоматическая загрузка при старте:**

1. Загружаются модели из `modelFiles`
2. После загрузки всех моделей (через 500ms) вызывается `loadModelPositions()`
3. Применяются позиции, повороты и масштабы из `model_positions.json`
4. Загружаются метки из секции `labels` или из localStorage

### Экспорт данных

**Функция `exportPositions()`:**

1. Собирает данные о всех моделях:
   - Позиции (`offset`)
   - Повороты (`rotation`)
   - Относительные масштабы (`scale`)
   - Пути к файлам (`file`)

2. Добавляет секцию `labels` со всеми метками

3. Создает JSON файл и автоматически скачивает его как `model_positions.json`

**Вызов:** Кнопка "Export Positions"

## API функций

### Управление моделями

#### `nudgeActiveModel(dx, dy, dz)`

Перемещает активную модель на указанное смещение.

**Параметры:**
- `dx` (number) — смещение по оси X
- `dy` (number) — смещение по оси Y
- `dz` (number) — смещение по оси Z

#### `rotateActiveModel(deltaYaw)`

Поворачивает активную модель вокруг оси Y.

**Параметры:**
- `deltaYaw` (number) — изменение угла поворота в радианах

#### `scaleActiveModel(scaleFactor)`

Масштабирует активную модель.

**Параметры:**
- `scaleFactor` (number) — множитель масштаба

#### `applyModelScale(axis, scaleValue)`

Применяет масштаб по конкретной оси относительно начального размера.

**Параметры:**
- `axis` (string) — ось: `'x'`, `'y'` или `'z'`
- `scaleValue` (number) — значение масштаба (относительное, 1.0 = 100%)

### Управление камерой

#### `updateCameraMovement()`

Обновляет позицию камеры на основе нажатых клавиш. Вызывается каждый кадр в функции `animate()`.

#### `updateModelRotation()`

Обновляет вращение активной модели при удержании клавиш Q/E. Вызывается каждый кадр.

### Работа с планом

#### `createFloor()`

Создает пол и сетку для ориентации в 3D пространстве.

#### `expandFloorToFitModels()`

Автоматически расширяет размер плана на основе позиций всех моделей.

**Алгоритм:**
1. Находит границы всех моделей (minX, maxX, minZ, maxZ)
2. Добавляет запас 20% от размера
3. Вычисляет новый размер плана
4. Обновляет геометрию пола и сетки

### Утилиты

#### `rgbToHex(rgba)`

Конвертирует RGBA строку в HEX формат.

**Параметры:**
- `rgba` (string) — строка вида `"rgba(74, 158, 255, 0.9)"`

**Возвращает:** `string` — HEX цвет вида `"#4a9eff"`

#### `hexToRgba(hex, alpha)`

Конвертирует HEX цвет в RGBA строку.

**Параметры:**
- `hex` (string) — HEX цвет вида `"#4a9eff"`
- `alpha` (number) — прозрачность (0-1)

**Возвращает:** `string` — RGBA строка

## Расширяемость

### Добавление новых моделей

1. Поместите OBJ файл в папку `models/`
2. Добавьте путь в массив `modelFiles`:
   ```javascript
   const modelFiles = [
     // ... существующие модели
     "models/новая_модель.obj"
   ];
   ```
3. Модель загрузится автоматически при следующем открытии страницы

### Добавление новых функций управления

1. Создайте функцию в `main.js`
2. Добавьте обработчик события в соответствующем месте
3. Обновите UI в `index.html` при необходимости

### Изменение стилей меток

Стили меток находятся в `styles.css`:

```css
.label {
  background: rgba(0, 0, 0, 0.7);
  color: #fff;
  padding: 8px 12px;
  border-radius: 4px;
  /* ... */
}
```

### Кастомизация цветов и размеров

Все константы находятся в начале файла `main.js`. Измените значения для настройки под ваши нужды.

## Обработка событий

### События мыши

- **click** — добавление меток (в режиме Add Label Mode)
- **mousedown/mousemove/mouseup** — управление камерой через OrbitControls
- **wheel** — зум камеры

### События клавиатуры

- **keydown/keyup** — отслеживание нажатых клавиш
- Обработка происходит каждый кадр в `updateCameraMovement()` и `updateModelRotation()`

### События окна

- **resize** — обновление размеров canvas и камеры
- **load** — инициализация приложения
- **error** — глобальная обработка ошибок

## Цикл рендеринга

### Функция `animate()`

Вызывается через `requestAnimationFrame()` и выполняет:

1. Обновление движения камеры (если не в режиме меток)
2. Обновление вращения моделей (если не в режиме позиционирования)
3. Обновление OrbitControls (если включены)
4. Рендеринг 3D сцены через `WebGLRenderer`
5. Рендеринг меток через `CSS2DRenderer`
6. Запрос следующего кадра
