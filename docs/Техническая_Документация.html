Техническая Документация: 3D Floor Plan Viewer

Внимание: Этот документ описывает внутреннее устройство и принципы работы веб-приложения для визуализации и позиционирования 3D моделей зданий на плане этажа.

1. Архитектура приложения

1.1. Общая структура

Приложение построено на базе библиотеки Three.js v0.169.0 и использует WebGL для рендеринга 3D графики. Three.js предоставляет высокоуровневый API для работы с 3D сценами, камерами, освещением и моделями, что упрощает разработку и обеспечивает кроссплатформенную совместимость.

1.2. Основные компоненты

Компонент Файл Назначение
HTML структура index.html Определяет canvas элемент для WebGL и панель управления (HUD)
Основная логика main.js Содержит весь код приложения: Three.js сцена, загрузка моделей через OBJLoader, управление камерой через OrbitControls, рендеринг через WebGLRenderer, система меток через CSS2DRenderer
Стили styles.css Оформление интерфейса и панели управления
Конфигурация model_positions.json Сохранённые позиции, повороты, масштабы всех моделей и меток (labels)

2. Three.js рендеринг

2.1. Инициализация сцены

При загрузке страницы создаётся Three.js сцена и рендерер:

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(55, aspect, 0.1, 10000);
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
const labelRenderer = new CSS2DRenderer(); // Для HTML меток

2.2. Рендеринг 3D объектов

Three.js автоматически обрабатывает:

  • Преобразование координат: Матрицы проекции и вида вычисляются автоматически
  • Освещение: Используются AmbientLight и DirectionalLight для реалистичного освещения
  • Материалы: MeshStandardMaterial с настройками metalness и roughness
  • Геометрия: Загружается через OBJLoader и обрабатывается Three.js

2.3. Рендеринг меток (CSS2DRenderer)

HTML метки рендерятся поверх 3D сцены через CSS2DRenderer:

  • Метки позиционируются в 3D пространстве через CSS2DObject
  • Автоматически отслеживают позицию камеры
  • Остаются видимыми при любом угле обзора
  • Поддерживают HTML/CSS стилизацию

2.4. Система матриц

Three.js автоматически управляет матрицами:

  • PerspectiveCamera: Создаёт матрицу перспективной проекции
    • FOV: 55 градусов
    • Near plane: 0.1
    • Far plane: 10000 (для видимости большого поля)
  • OrbitControls: Автоматически обновляет матрицу вида камеры
  • Object3D: Каждая модель имеет свою матрицу трансформации

3. Загрузка и обработка 3D моделей

3.1. Загрузка OBJ файлов через OBJLoader

Функция loadAllModels() использует OBJLoader из Three.js для загрузки моделей:

  1. Инициализация загрузчика: const loader = new OBJLoader();
  2. Асинхронная загрузка: Для каждого файла создаётся Promise с использованием loader.load()
  3. Обработка загруженной модели:
    • Вычисление границ модели через THREE.Box3().setFromObject()
    • Определение центра и размеров модели
    • Масштабирование под размер плана (90% от PLAN_SIZE)
    • Центрирование модели
    • Выравнивание по полу (поднятие над планом)
    • Применение материала MeshStandardMaterial к каждой части модели
    • Вычисление нормалей через geometry.computeVertexNormals()
  4. Обработка всех моделей: Используется Promise.allSettled() для параллельной загрузки
  5. Применение позиций: После загрузки применяются позиции из model_positions.json

3.2. Структура данных модели

Каждая модель загружается как THREE.Object3D (группа) и содержит:

  • Дочерние объекты: Каждая часть модели (mesh) является дочерним объектом
  • Геометрия: THREE.BufferGeometry с атрибутами:
    • position — координаты вершин
    • normal — нормали вершин
    • uv — UV координаты (если есть)
  • Материал: THREE.MeshStandardMaterial с настройками цвета, metalness, roughness
  • Трансформации: position, rotation, scale для позиционирования в сцене

3.3. Обработка моделей после загрузки

После загрузки всех моделей выполняется:

  1. Вычисление высот: Для каждой модели вычисляется высота через Box3.getSize()
  2. Применение позиций из JSON: Загружаются позиции, повороты и масштабы из model_positions.json
  3. Расширение плана: План автоматически расширяется под все модели через expandFloorToFitModels()
  4. Загрузка меток: Загружаются метки из секции labels файла model_positions.json

Примечание: Нормализация высоты моделей отключена в текущей версии. Каждая модель сохраняет свои пропорции.

4. Система камеры

4.1. OrbitControls

Камера управляется через THREE.OrbitControls, который автоматически обрабатывает:

  • target: Точка в пространстве, на которую направлена камера (устанавливается через controls.target.set())
  • distance: Расстояние от target до камеры (60-2000 единиц, управляется колёсиком мыши)
  • Вращение: Горизонтальный и вертикальный углы (управляются перетаскиванием мыши)
  • Damping: Плавное движение камеры (enableDamping = true, dampingFactor = 0.05)

4.2. Ограничения камеры

OrbitControls автоматически применяет ограничения:

  • minDistance: 60 единиц — минимальное приближение
  • maxDistance: 2000 единиц — максимальное отдаление
  • minPolarAngle: 0.2 радиан — минимальный угол наклона (нельзя смотреть снизу)
  • maxPolarAngle: 1.88 радиан (π * 0.6) — максимальный угол наклона

4.3. Управление камерой

Мышь (OrbitControls)

  • Перетаскивание: Вращение камеры вокруг target (автоматически обрабатывается OrbitControls)
  • Колёсико: Приближение/отдаление камеры (автоматически обрабатывается OrbitControls)

Клавиатура (дополнительное управление)

Система отслеживает нажатые клавиши через объект keys и обновляет позицию камеры каждый кадр в функции updateCameraMovement():

  • Стрелки/WASD: Движение камеры по горизонтали
    • Вычисляются векторы "вперёд" и "влево" на основе направления камеры
    • Применяется скорость движения (5.0 единиц за кадр)
    • Обновляются позиция камеры и target синхронно
  • Space/PageUp: Движение камеры вверх (изменяет позицию камеры и target по оси Y)
  • Shift/PageDown: Движение камеры вниз
  • R: Сброс камеры к начальной позиции (camera.position.set(0, 480, 480), target.set(0, 2, -10))

Отключение управления

При включении режима "Add Label Mode" управление камерой полностью отключается:

  • controls.enabled = false — OrbitControls отключается
  • Движение камеры через клавиатуру блокируется в функции updateCameraMovement()
  • При выключении режима управление автоматически включается обратно

5. Позиционирование моделей

5.1. Структура данных позиционирования

Для каждой модели хранятся:

  • modelOffsets[modelKey]: Смещение модели {x, y, z} — позиция модели в сцене
  • modelRotations[modelKey]: Поворот модели {yaw} — угол поворота вокруг оси Y
  • initialModelScales[modelKey]: Начальные масштабы модели {x, y, z} — для вычисления относительных масштабов

5.2. Применение трансформаций

Three.js автоматически применяет трансформации к моделям через свойства объекта:

  • model.position.set(x, y, z): Устанавливает позицию модели в сцене
  • model.rotation.y = yaw: Устанавливает поворот вокруг оси Y
  • model.scale.set(sx, sy, sz): Устанавливает масштаб модели

При изменении этих свойств Three.js автоматически обновляет матрицу трансформации модели.

5.3. Управление позиционированием

В режиме Position Mode (включается кнопкой "Position Mode: On"):

  • Стрелки вверх/вниз: Перемещение активной модели по оси Z
  • Стрелки влево/вправо: Перемещение активной модели по оси X
  • Q: Поворот модели против часовой стрелки (дискретный шаг)
  • E: Поворот модели по часовой стрелке (дискретный шаг)
  • Space / PageUp: Поднять модель (увеличить Y)
  • Shift / PageDown: Опустить модель (уменьшить Y)
  • 1-9: Выбор активной модели

Вне режима Position Mode:

  • Q/E: Плавное вращение активной модели (при удержании клавиш, скорость: ROTATION_STEP * 0.5)
  • 1-9: Выбор активной модели

5.4. Масштабирование моделей

Ползунки в панели управления позволяют масштабировать активную модель по осям:

  • Диапазон: 10% - 300% от исходного размера
  • Масштабирование: Относительно центра модели (позиция модели сохраняется)
  • Сохранение: Относительные масштабы сохраняются в model_positions.json (1.0 = 100%)

6. Цикл рендеринга

6.1. Функция animate()

Вызывается каждый кадр через requestAnimationFrame() и выполняет:

  1. Обновление движения камеры: updateCameraMovement() — обрабатывает нажатые клавиши (только если не в режиме меток)
  2. Обновление вращения моделей: updateModelRotation() — обрабатывает Q/E клавиши (только если не в режиме позиционирования)
  3. Обновление OrbitControls: controls.update() — обновляет позицию камеры (только если controls.enabled = true)
  4. Рендеринг 3D сцены: renderer.render(scene, camera) — отрисовывает все объекты в сцене:
    • Пол (PlaneGeometry) — если включен
    • Сетка (GridHelper) — если включен план
    • Все модели (загруженные через OBJLoader)
    • Освещение (AmbientLight, DirectionalLight)
  5. Рендеринг меток: labelRenderer.render(scene, camera) — отрисовывает HTML метки поверх 3D сцены
  6. Запрос следующего кадра: requestAnimationFrame(animate)

6.2. Обработка ошибок

Приложение использует глобальные обработчики ошибок:

  • window.addEventListener("error") — обработка JavaScript ошибок
  • window.addEventListener("unhandledrejection") — обработка необработанных Promise rejections
  • Проверка наличия canvas элемента перед инициализацией
  • Проверка успешной загрузки моделей через Promise.allSettled()
  • Ошибки логируются в консоль, но не прерывают работу приложения

7. Загрузка и сохранение позиций

7.1. Автоматическая загрузка позиций

При загрузке страницы (через 500ms после загрузки моделей) вызывается loadModelPositions():

  1. Загружается файл model_positions.json через fetch()
  2. Для каждой модели из JSON:
    • Применяются позиции (offset), повороты (rotation) и масштабы (scale)
    • Масштабы интерпретируются как относительные значения (1.0 = 100%)
    • Обновляется позиция модели в сцене
  3. После применения позиций моделей вызывается loadLabelsFromJSON():
    • Пытается загрузить метки из секции labels файла model_positions.json
    • Если секция отсутствует, загружает из localStorage
    • Создает метки в сцене с сохраненными параметрами

7.2. Экспорт позиций

Функция exportPositions() создаёт JSON файл со всеми позициями моделей и меток:

  • Модели: Собирает данные из позиций, поворотов и относительных масштабов всех моделей
  • Метки: Добавляет секцию labels со всеми метками (текст, позиция, стили, привязка к модели)
  • Экспорт: Создаёт Blob и автоматически скачивает файл model_positions.json

7.3. Сохранение меток

Функция saveLabelsToJSON() вызывается при каждом изменении меток:

  • Сохраняет метки только в localStorage (без автоматического скачивания файла)
  • Метки включаются в экспорт только при нажатии кнопки "Export Positions"
  • Это предотвращает множественные скачивания файлов при редактировании

8. Оптимизации и производительность

8.1. Оптимизации Three.js

  • BufferGeometry: Three.js автоматически использует BufferGeometry для эффективного хранения данных вершин
  • Статические буферы: Данные моделей загружаются в GPU один раз и переиспользуются
  • Frustum Culling: Three.js автоматически отсекает объекты вне видимости камеры
  • Pixel Ratio: Ограничен до 2 для предотвращения избыточного рендеринга на Retina дисплеях

8.2. Оптимизации меток

  • CSS2DRenderer: Метки рендерятся как HTML элементы, что эффективнее чем создание 3D текста
  • Обновление по требованию: Панель меток обновляется только при открытии или изменении меток
  • Локальное хранение: Метки сохраняются в localStorage для быстрого доступа

8.3. Проверки валидности

  • Проверка существования моделей перед операциями
  • Проверка наличия элементов DOM перед использованием
  • Проверка валидности индексов моделей (1-9)
  • Обработка ошибок загрузки через Promise.allSettled()

9. Обработка событий

9.1. События мыши

  • mousedown/mousemove/mouseup: Управление камерой через OrbitControls (вращение, перетаскивание)
  • wheel: Изменение расстояния камеры (zoom) через OrbitControls
  • click (canvas):
    • В обычном режиме: установка фокуса на canvas для обработки клавиатуры
    • В режиме "Add Label Mode": создание метки в точке клика
      • Клик по модели: создает метку, привязанную к модели
      • Клик по пустому месту: создает свободную метку на плоскости
      • Клик по UI элементам: игнорируется
  • click (метка): Открывает модальное окно для редактирования метки

9.2. События клавиатуры

Система отслеживает нажатые клавиши через объект keys и обрабатывает их каждый кадр:

Управление камерой (в обычном режиме):

  • WASD / Стрелки: Движение камеры по горизонтали
  • Space / PageUp: Движение камеры вверх
  • Shift / PageDown: Движение камеры вниз
  • R: Сброс камеры к начальной позиции

Управление моделями:

  • 1-9: Выбор активной модели
  • Q/E: Вращение активной модели (в обычном режиме — плавное, в Position Mode — дискретное)

Режим позиционирования (Position Mode):

  • Стрелки: Перемещение активной модели (вверх/вниз — по Z, влево/вправо — по X)
  • Space / PageUp: Поднять модель (ось Y)
  • Shift / PageDown: Опустить модель (ось Y)
  • Q/E: Поворот модели (дискретный шаг)

Примечание: В режиме "Add Label Mode" управление камерой и моделями отключается.

9.3. События окна

  • resize: Обновление размеров canvas при изменении размера окна
  • load: Установка фокуса на canvas при загрузке страницы
  • error: Глобальный обработчик ошибок для предотвращения перезагрузки страницы
  • unhandledrejection: Обработка необработанных Promise rejections

11. Алгоритмы и математика

11.1. Вычисление границ модели

Используется THREE.Box3().setFromObject(model) для автоматического вычисления:

  • Минимальные и максимальные координаты: По всем осям (min, max)
  • Центр модели: box.getCenter(center) — средняя точка между min и max
  • Размер модели: box.getSize(size) — разница между max и min по каждой оси

11.2. Вычисление нормалей

Three.js автоматически вычисляет нормали через geometry.computeVertexNormals():

  • Если нормали отсутствуют в OBJ файле, вычисляются автоматически
  • Используется алгоритм с учетом углов граней для плавного затенения
  • Параметр true включает использование углов граней для весов нормалей

11.3. Масштабирование моделей

При загрузке модели масштабируются под размер плана:

const maxDim = Math.max(size.x, size.z);
const scale = (PLAN_SIZE * 0.9) / maxDim;
model.scale.multiplyScalar(scale);

При изменении масштаба через ползунки:

// Относительный масштаб = текущий / начальный
const relativeScale = currentScale / initialScale;

// Применение к модели
model.scale.set(
  initialScale.x * relativeScaleX,
  initialScale.y * relativeScaleY,
  initialScale.z * relativeScaleZ
);

11.4. Raycasting для определения клика

При клике в режиме "Add Label Mode" используется THREE.Raycaster:

  1. Нормализация координат мыши в диапазон [-1, 1]
  2. Создание луча из камеры через точку клика
  3. Проверка пересечения с моделями через raycaster.intersectObjects()
  4. Если пересечение найдено — создается метка на модели, иначе — на плоскости

12. Обработка ошибок и отладка

12.1. Проверки валидности

  • Проверка наличия canvas элемента перед инициализацией
  • Проверка успешной загрузки моделей через Promise.allSettled()
  • Проверка наличия элементов DOM перед использованием (labelsList, кнопки и т.д.)
  • Проверка валидности индексов моделей (1-9) перед операциями
  • Проверка существования меток перед редактированием/удалением
  • Обработка ошибок загрузки файлов через try-catch

12.2. Логирование

Приложение использует console.log(), console.warn() и console.error() для отладки:

  • Успешная загрузка моделей и их количество
  • Размеры и позиции моделей после загрузки
  • Расширение плана под модели
  • Загрузка позиций из JSON
  • Загрузка меток (количество и источник)
  • Инициализация кнопок и UI элементов
  • Состояние режимов (Position Mode, Add Label Mode)
  • Ошибки загрузки файлов и обработки данных

12.3. Глобальные обработчики ошибок

  • window.addEventListener("error") — перехватывает все JavaScript ошибки
  • window.addEventListener("unhandledrejection") — обрабатывает необработанные Promise rejections
  • Ошибки логируются в консоль, но не прерывают работу приложения

13. Расширяемость

13.1. Добавление новых моделей

  1. Поместить OBJ файл в папку models/
  2. Добавить путь в массив modelFiles в файле main.js: 
    const modelFiles = [
  // ... существующие модели
  "models/новая_модель.obj"
];
  3. Модель загрузится автоматически при следующем открытии страницы
  4. Позиция модели будет загружена из model_positions.json (если указана)

13.2. Добавление новых функций меток

Для расширения функциональности меток можно:

  • Добавить новые поля в структуру данных метки (в функции createNewLabel)
  • Добавить новые опции стилизации в функцию createLabel
  • Создать новые типы меток (например, с иконками или изображениями)
  • Добавить анимации появления/исчезновения меток

13.3. Изменение настроек

  • Размер плана: Изменить PLAN_SIZE (по умолчанию: 1100)
  • Скорости движения: Изменить значение в updateCameraMovement() (по умолчанию: 5.0)
  • Шаг перемещения: Изменить POSITION_STEP (по умолчанию: PLAN_SIZE * 0.01)
  • Шаг поворота: Изменить ROTATION_STEP (по умолчанию: Math.PI / 36)
  • Ограничения камеры: Изменить minDistance, maxDistance, minPolarAngle, maxPolarAngle в OrbitControls
  • Цвета и материалы: Изменить значения в MeshStandardMaterial при загрузке моделей

14. Система меток (Labels)

14.1. Обзор

Система меток позволяет добавлять интерактивные HTML-элементы в 3D-пространство. Метки автоматически следуют за моделями при их перемещении и могут быть привязаны к конкретным моделям или размещены в произвольных точках сцены.

14.2. Основные возможности

  • Создание меток: Клик по модели или сцене в режиме "Add Label Mode"
  • Редактирование меток: Клик по метке для открытия редактора
  • Управление метками: Панель со списком всех меток
  • Сохранение и загрузка: Метки сохраняются в model_positions.json вместе с моделями

14.3. Структура данных метки

{
  "labels": {
    "label_1234567890_abc123": {
      "text": "Название метки",
      "position": {"x": 100.0, "y": 50.0, "z": -200.0},
      "modelIndex": 1,
      "backgroundColor": "rgba(74, 158, 255, 0.9)",
      "color": "#ffffff",
      "fontSize": "14px",
      "offsetY": 30
    }
  }
}

14.4. Режим добавления меток

При включении режима "Add Label Mode":

  • Курсор меняется на крестик
  • Управление камерой отключается (controls.enabled = false)
  • Клик по модели создает метку, привязанную к модели
  • Клик по пустому месту создает свободную метку
