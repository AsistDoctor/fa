Техническая Документация: 3D Floor Plan Viewer

Внимание: Этот документ описывает внутреннее устройство и принципы работы веб-приложения для визуализации и позиционирования 3D моделей зданий на плане этажа.

1. Архитектура приложения

1.1. Общая структура

Приложение построено на базе WebGL API и использует низкоуровневый рендеринг без использования сторонних библиотек (Three.js, Babylon.js и т.д.). Это обеспечивает полный контроль над процессом отрисовки и оптимизацию производительности.

1.2. Основные компоненты

Компонент Файл Назначение
HTML структура index.html Определяет canvas элемент для WebGL и панель управления (HUD)
Основная логика main.js Содержит весь код приложения: шейдеры, загрузку моделей, управление камерой, рендеринг
Стили styles.css Оформление интерфейса и панели управления
Конфигурация model_positions.json Сохранённые позиции и повороты всех моделей

2. WebGL рендеринг

2.1. Инициализация WebGL контекста

При загрузке страницы создаётся WebGL контекст из canvas элемента:

const canvas = document.querySelector("#c");
const gl = canvas.getContext("webgl");

Если WebGL недоступен, выводится сообщение об ошибке через функцию showError().

2.2. Шейдеры

Вершинный шейдер (Vertex Shader)

Обрабатывает каждую вершину модели и выполняет следующие операции:

  • Преобразование координат: Применяет матрицу проекции и вида (u_viewProj)
  • Вычисление освещения: Использует нормали вершин и направление света для расчёта яркости
  • Передача данных: Передаёт цвет, UV координаты, освещённость и высоту во фрагментный шейдер
attribute vec3 a_position;    // Позиция вершины
attribute vec3 a_normal;      // Нормаль вершины
attribute vec2 a_uv;          // UV координаты для текстуры
attribute vec3 a_color;       // Цвет вершины
uniform mat4 u_viewProj;      // Матрица проекции и вида
uniform vec3 u_lightDir;      // Направление света

Фрагментный шейдер (Fragment Shader)

Обрабатывает каждый пиксель и определяет его цвет:

  • Базовый цвет: Использует цвет вершины или текстуру (если доступна)
  • Освещение: Применяет вычисленную яркость для создания объёма
  • Межэтажные полосы: Опционально добавляет светящиеся полосы между этажами (отключено в текущей версии)

2.3. Система матриц

Приложение использует собственные функции для работы с матрицами (совместимые с glMatrix):

  • mat4Perspective: Создаёт матрицу перспективной проекции
    • Параметры: угол обзора (55°), соотношение сторон, ближняя плоскость (0.1), дальняя плоскость (10000)
    • Дальняя плоскость увеличена до 10000 единиц для видимости большого поля
  • mat4LookAt: Создаёт матрицу вида камеры
    • Параметры: позиция камеры (eye), точка наблюдения (target), вектор "вверх"
  • mat4Multiply: Умножает две матрицы (проекция × вид)

3. Загрузка и обработка 3D моделей

3.1. Парсинг OBJ файлов

Функция loadOBJModel() выполняет следующие шаги:

  1. Загрузка файла: Использует fetch() для асинхронной загрузки OBJ файла
  2. Парсинг строк: Разбивает файл на строки и обрабатывает каждую:
    • v x y z → вершина (сохраняется в массив vertices)
    • vn x y z → нормаль (сохраняется в массив normals)
    • f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3 → грань (сохраняется в массив faces)
  3. Определение системы индексации: Автоматически определяет, используется ли 0-based или 1-based индексация
  4. Вычисление границ модели: Находит минимальные и максимальные координаты по всем осям
  5. Центрирование: Вычисляет центр модели для последующего позиционирования
  6. Масштабирование: Масштабирует модель под размер плана (90% от PLAN_SIZE)
  7. Выравнивание по полу: Поднимает модель над планом с заданным зазором
  8. Создание треугольников: Разбивает многоугольные грани на треугольники (fan triangulation)
  9. Вычисление нормалей: Если нормали не указаны в файле, вычисляет их для каждого треугольника

3.2. Структура данных модели

Каждая модель хранится в объекте mesh со следующими массивами:

{
  positions: [],  // Координаты вершин [x, y, z, x, y, z, ...]
  normals: [],    // Нормали вершин [nx, ny, nz, nx, ny, nz, ...]
  colors: [],     // Цвета вершин [r, g, b, r, g, b, ...]
  uvs: []         // UV координаты [u, v, u, v, ...]
}

3.3. Нормализация высоты моделей

После загрузки всех моделей выполняется функция normalizeModelHeights():

  1. Вычисление высот: Для каждой модели вычисляется высота (разница между maxY и minY)
  2. Поиск максимума: Находится максимальная высота среди всех моделей
  3. Масштабирование: Для каждой модели вычисляется коэффициент: scaleY = maxHeight / currentHeight
  4. Применение масштабирования: Все вершины масштабируются по оси Y относительно центра модели: 
    scaledY = centerY + (originalY - centerY) * scaleY
  5. Обновление данных: Обновляются базовые позиции, центры и GPU буферы

Важно: Масштабирование происходит только по оси Y, сохраняя пропорции по осям X и Z.

4. Система камеры

4.1. Орбитальная модель камеры

Камера использует орбитальную модель с параметрами:

  • target: Точка в пространстве, на которую направлена камера [x, y, z]
  • distance: Расстояние от target до камеры (60-2000 единиц)
  • yaw: Горизонтальный угол поворота вокруг оси Y (в радианах)
  • pitch: Вертикальный угол наклона (0.2-2.2 радиан)

4.2. Вычисление позиции камеры

Функция getCameraPosition() вычисляет позицию камеры на основе параметров:

const x = target[0] + cos(pitch) * sin(yaw) * distance;
const y = target[1] + sin(pitch) * distance;
const z = target[2] + cos(pitch) * cos(yaw) * distance;

4.3. Управление камерой

Мышь

  • Перетаскивание: Изменяет yaw и pitch камеры
  • Колёсико: Изменяет distance (приближение/отдаление)

Клавиатура

Система отслеживает нажатые клавиши через объект keys и обновляет позицию камеры каждый кадр в функции updateCameraMovement():

  • Стрелки/WASD: Движение камеры по горизонтали
    • Вычисляются векторы "вперёд" и "влево" на основе yaw
    • Применяется скорость движения (5.0 единиц за кадр)
  • Space/PageUp: Движение камеры вверх (изменяет target[1])
  • Shift/PageDown: Движение камеры вниз
  • R: Сброс камеры к начальной позиции

5. Позиционирование моделей

5.1. Структура данных позиционирования

Для каждой модели хранятся:

  • modelOffsets[modelKey]: Смещение модели {x, y, z}
  • modelRotations[modelKey]: Поворот модели {yaw}
  • modelBasePositions[modelKey]: Исходные позиции вершин (до трансформаций)
  • modelBaseCenters[modelKey]: Центр модели

5.2. Применение трансформаций

Функция applyTransformFromBase() применяет поворот и смещение к модели:

  1. Вершины переводятся относительно центра модели
  2. Применяется поворот вокруг оси Y: 
    rx = x * cos(yaw) - z * sin(yaw);
rz = x * sin(yaw) + z * cos(yaw);
  3. Применяется смещение (offset)
  4. Обновляется массив positions модели

5.3. Управление позиционированием

В режиме Position Mode (включается кнопкой):

  • Стрелки: Перемещение активной модели по горизонтали
  • Q/E: Вращение активной модели
  • PageUp/PageDown: Перемещение модели вверх/вниз
  • 1-7: Выбор активной модели

Вне режима Position Mode:

  • Q/E: Плавное вращение активной модели (при удержании клавиш)
  • 1-7: Выбор активной модели

6. Цикл рендеринга

6.1. Функция render()

Вызывается каждый кадр через requestAnimationFrame() и выполняет:

  1. Обновление движения камеры: updateCameraMovement() — обрабатывает нажатые клавиши
  2. Обновление вращения моделей: updateModelRotation() — обрабатывает Q/E клавиши
  3. Очистка буферов: Очищает цветовой и глубинный буферы
  4. Вычисление матриц: Создаёт матрицы проекции и вида
  5. Установка uniform переменных: Передаёт данные в шейдеры (матрицы, свет, текстуры)
  6. Отрисовка сцены:
    • Пол (если включен) — отрисовывается без depth test
    • Сетка (если включен план) — отрисовывается поверх пола
    • Все модели — перебираются и отрисовываются
    • Стены и комнаты (если есть)
  7. Запрос следующего кадра: requestAnimationFrame(render)

6.2. Обработка ошибок

Функция render() обёрнута в try-catch блок для предотвращения падений:

  • Проверяется наличие WebGL контекста
  • Проверяется валидность размеров canvas
  • Проверяется существование мешей перед отрисовкой
  • Ошибки логируются в консоль, но не прерывают рендеринг

7. Загрузка и сохранение позиций

7.1. Автоматическая загрузка позиций

При загрузке страницы (через 3 секунды после загрузки моделей) вызывается loadModelPositions():

  1. Загружается файл model_positions.json через fetch()
  2. Для каждой модели из JSON:
    • Обновляются modelOffsets и modelRotations
    • Применяется трансформация через applyTransformFromBase()
    • Обновляется GPU буфер модели

7.2. Экспорт позиций

Функция exportPositions() создаёт JSON файл со всеми позициями:

  • Собирает данные из modelOffsets и modelRotations для всех моделей
  • Добавляет информацию о файлах моделей
  • Создаёт Blob и скачивает файл через элемент <a>

8. Оптимизации и производительность

8.1. GPU буферы

  • VAO (Vertex Array Objects): Используются для ускорения отрисовки (если поддерживаются)
  • Статические буферы: Данные загружаются в GPU один раз и переиспользуются
  • Обновление по требованию: GPU буферы обновляются только при изменении модели

8.2. Проверки валидности

  • Проверка существования мешей перед отрисовкой
  • Проверка количества вершин (count > 0)
  • Проверка наличия буферов
  • Проверка валидности математических операций (isFinite)

9. Обработка событий

9.1. События мыши

  • mousedown: Начало перетаскивания камеры
  • mousemove: Обновление углов камеры при перетаскивании
  • mouseup: Окончание перетаскивания
  • wheel: Изменение расстояния камеры (zoom)
  • click: Установка фокуса на canvas для обработки клавиатуры

9.2. События клавиатуры

  • keydown: Установка флагов в объекте keys для отслеживания нажатых клавиш
  • keyup: Сброс флагов при отпускании клавиш
  • Обработка происходит в каждом кадре рендеринга для плавного движения

9.3. События окна

  • resize: Обновление размеров canvas при изменении размера окна
  • load: Установка фокуса на canvas при загрузке страницы
  • error: Глобальный обработчик ошибок для предотвращения перезагрузки страницы
  • unhandledrejection: Обработка необработанных Promise rejections

11. Алгоритмы и математика

11.1. Вычисление центра модели

Функция computeMeshCenter():

  1. Проходит по всем вершинам и находит min/max по каждой оси
  2. Вычисляет центр как среднее между min и max: 
    centerX = (minX + maxX) / 2;
centerY = (minY + maxY) / 2;
centerZ = (minZ + maxZ) / 2;

11.2. Вычисление нормалей

Если нормали не указаны в OBJ файле, вычисляются для каждого треугольника:

// Векторы сторон треугольника
dx1 = x1 - x0; dy1 = y1 - y0; dz1 = z1 - z0;
dx2 = x2 - x0; dy2 = y2 - y0; dz2 = z2 - z0;

// Векторное произведение (нормаль)
nx = dy1 * dz2 - dz1 * dy2;
ny = dz1 * dx2 - dx1 * dz2;
nz = dx1 * dy2 - dy1 * dx2;

// Нормализация
length = sqrt(nx² + ny² + nz²);
normal = [nx/length, ny/length, nz/length];

11.3. Поворот вокруг оси Y

При вращении модели применяется матрица поворота вокруг вертикальной оси:

cosY = cos(yaw);
sinY = sin(yaw);

// Поворот относительно центра
x_rel = x - centerX;
z_rel = z - centerZ;

rx = x_rel * cosY - z_rel * sinY;
rz = x_rel * sinY + z_rel * cosY;

// Возврат к глобальным координатам
x_new = rx + centerX + offsetX;
z_new = rz + centerZ + offsetZ;

12. Обработка ошибок и отладка

12.1. Проверки валидности

  • Проверка наличия WebGL контекста
  • Проверка компиляции шейдеров
  • Проверка линковки программы
  • Проверка наличия вершин в OBJ файле
  • Проверка валидности индексов граней
  • Проверка математических операций (isFinite)

12.2. Логирование

Приложение использует console.log(), console.warn() и console.error() для отладки:

  • Успешная загрузка моделей
  • Высоты моделей при загрузке
  • Нормализация высоты
  • Загрузка позиций
  • Ошибки загрузки и рендеринга

13. Расширяемость

13.1. Добавление новых моделей

  1. Поместить OBJ файл в папку models/
  2. Добавить путь в массив modelFiles
  3. Убедиться, что есть достаточно мешей в buildingMeshes
  4. Модель загрузится автоматически при следующем открытии страницы

13.2. Изменение настроек

  • Размер плана: Изменить PLAN_SIZE
  • Размер сетки: Изменить GRID_CELL_SIZE
  • Скорости: Изменить константы в функциях движения
  • Цвета: Изменить значения в массивах цветов
  • Ограничения камеры: Изменить min/max значения в обработчиках событий

14. Заключение

Приложение представляет собой полнофункциональный 3D редактор, построенный на базе WebGL без использования сторонних библиотек. Основные особенности:

  • Полный контроль над процессом рендеринга
  • Эффективная обработка нескольких 3D моделей
  • Интерактивное управление камерой и моделями
  • Автоматическая нормализация высоты моделей
  • Сохранение и загрузка позиций
  • Обработка ошибок для стабильной работы

Код структурирован и легко расширяется для добавления новых функций и возможностей.
