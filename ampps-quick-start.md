# Быстрый старт с AMPPS (Вариант 1)

## Шаги:

### 1. Запустите скрипт копирования
Дважды кликните на файл `copy-to-ampps.bat`
- Скрипт автоматически найдет папку www AMPPS
- Скопирует весь проект туда

**Или вручную:**
1. Откройте папку: `C:\Program Files (x86)\Ampps\www`
2. Скопируйте всю папку проекта `fa-main` туда

### 2. Запустите AMPPS
1. Откройте AMPPS Control Panel
2. Убедитесь, что Apache запущен (зеленая галочка)
3. Если не запущен - нажмите "Start" рядом с Apache

### 3. Откройте проект в браузере
```
http://localhost/fa-main/index.html
```

### 4. Для доступа из сети
1. Узнайте ваш локальный IP:
   - Откройте командную строку
   - Введите: `ipconfig`
   - Найдите IPv4 адрес (например, 192.168.1.100)

2. Откройте в браузере на другом компьютере:
   ```
   http://192.168.1.100/fa-main/index.html
   ```

3. Убедитесь, что брандмауэр Windows разрешает подключения на порт 80

## Проверка работы:
- Откройте консоль браузера (F12)
- Проверьте, что нет ошибок загрузки файлов
- Убедитесь, что модели загружаются из папки `models/`

## Если что-то не работает:
- **403 Forbidden**: Проверьте права доступа к папке www
- **Модели не загружаются**: Проверьте пути в `main.js` (должны быть `models/...`)
- **CORS ошибки**: Убедитесь, что файл `.htaccess` скопировался в папку проекта
