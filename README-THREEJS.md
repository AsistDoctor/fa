# Three.js Refactored Version

Эта ветка содержит рефакторинг проекта с использованием Three.js вместо чистого WebGL.

## 🚀 Преимущества

- **Код сократился с ~1700 строк до ~600 строк** (упрощение в 3 раза!)
- **Автоматическое управление буферами** - больше не нужно вручную управлять GPU буферами
- **Встроенные контролы камеры** - OrbitControls из коробки
- **Простая загрузка моделей** - OBJLoader делает всю работу
- **Лучшая производительность** - оптимизированный рендерер Three.js
- **Проще поддерживать** - меньше низкоуровневого кода

## 📦 Установка

```bash
npm install
```

## 🎮 Использование

### Вариант 1: Использовать Three.js версию напрямую

Откройте `index-threejs.html` в браузере или через сервер:

```bash
npm start
# Затем откройте http://localhost:3000/index-threejs.html
```

### Вариант 2: Переключить основной файл

1. Переименуйте `main.js` в `main-webgl.js` (резервная копия)
2. Переименуйте `main-threejs.js` в `main.js`
3. Обновите `index.html` чтобы использовать `main.js`

## 🔄 Переключение между версиями

### Использовать Three.js версию:
```bash
# Windows
ren main.js main-webgl.js
ren main-threejs.js main.js
```

### Вернуться к WebGL версии:
```bash
# Windows
ren main.js main-threejs.js
ren main-webgl.js main.js
```

## 🛠 Технические детали

### Что изменилось:

1. **Шейдеры** → Three.js материалы (MeshStandardMaterial)
2. **Ручные матрицы** → Встроенные матрицы Three.js
3. **Ручной парсинг OBJ** → OBJLoader
4. **Ручное управление камерой** → OrbitControls + кастомное движение
5. **Ручные буферы** → Автоматическое управление Three.js

### Зависимости:

- `three` ^0.169.0 - основная библиотека
- `three/examples/jsm/loaders/OBJLoader` - загрузчик OBJ
- `three/examples/jsm/controls/OrbitControls` - контролы камеры

## 📝 Примечания

- Оригинальный код сохранён в `main.js` (WebGL версия)
- Three.js версия в `main-threejs.js`
- Обе версии используют один и тот же `model_positions.json`
- Обе версии совместимы с существующими моделями

## 🐛 Известные отличия

1. **Экспорт OBJ** - упрощённая версия (экспортирует только первую модель)
2. **Освещение** - использует стандартное освещение Three.js (можно настроить)
3. **Производительность** - должна быть лучше, но зависит от браузера
