Документация: 3D Floor Plan Viewer

1. Общее описание

3D Floor Plan Viewer — это веб-приложение на основе WebGL для визуализации и позиционирования 3D моделей зданий на интерактивном плане этажа. Приложение позволяет загружать несколько 3D моделей в формате OBJ, размещать их на плане, вращать и экспортировать их позиции.

2. Архитектура приложения

2.1. Основные компоненты

  • HTML структура (index.html) — Canvas элемент для WebGL рендеринга и панель управления
  • JavaScript логика (main.js) — WebGL шейдеры, загрузка OBJ, управление камерой, рендеринг
  • Стили (styles.css) — оформление интерфейса

2.2. WebGL рендеринг

Приложение использует WebGL для отрисовки 3D сцены:

  • Вершинный шейдер обрабатывает позиции вершин, нормали, цвета и UV координаты
  • Фрагментный шейдер вычисляет освещение и применяет текстуры
  • Используется система матриц для преобразований (проекция, вид, модель)

3. Загрузка и обработка моделей

3.1. Парсинг OBJ файлов

  1. Чтение вершин (v x y z)
  2. Чтение нормалей (vn x y z)
  3. Парсинг граней (f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3)
  4. Автоматическое определение системы индексации (0-based или 1-based)

3.2. Обработка моделей

  • Вычисление границ модели (bounding box)
  • Центрирование модели
  • Масштабирование под размер плана
  • Выравнивание по полу с заданным зазором

3.3. Нормализация высоты

После загрузки всех моделей:

  1. Находится максимальная высота среди всех моделей
  2. Все модели масштабируются по оси Y до этой максимальной высоты
  3. Масштабирование происходит относительно центра модели

4. Система камеры

Камера использует орбитальную модель с параметрами:

  • target — точка, на которую направлена камера
  • distance — расстояние от target до камеры (60-2000 единиц)
  • yaw — горизонтальный угол поворота
  • pitch — вертикальный угол наклона (0.2-2.2 радиан)

5. Позиционирование моделей

Каждая модель имеет:

  • offset — смещение по осям X, Y, Z
  • rotation — поворот вокруг оси Y (yaw)
  • basePositions — исходные позиции вершин
  • baseCenters — центр модели

При изменении позиции или поворота применяется трансформация:

  1. Вершины переводятся относительно центра модели
  2. Применяется поворот вокруг оси Y
  3. Применяется смещение (offset)
  4. Обновляется GPU буфер для отрисовки

6. Управление

6.1. Управление камерой

  • Мышь: перетаскивание — вращение камеры, колёсико — зум
  • Стрелки/WASD: движение камеры по горизонтали
  • Space/PageUp: движение камеры вверх
  • Shift/PageDown: движение камеры вниз
  • R: сброс позиции камеры

6.2. Управление моделями

  • 1-7: выбор активной модели
  • Q/E: вращение выбранной модели (работает всегда)
  • Position Mode: включить/выключить режим позиционирования
  • В Position Mode: стрелки — перемещение, Q/E — вращение, PageUp/Down — движение вверх/вниз

7. Экспорт и импорт данных

7.1. Экспорт

  • Export to OBJ: экспортирует активную модель в формат OBJ
  • Export Positions: сохраняет все позиции и повороты моделей в JSON файл

7.2. Импорт

При загрузке страницы автоматически загружается файл model_positions.json:

  • Применяются сохранённые позиции моделей
  • Применяются сохранённые повороты
  • Модели перемещаются в указанные позиции

8. Структура данных

8.1. model_positions.json

{
  "model1": {
    "offset": { "x": 1650, "y": 0, "z": -539 },
    "rotation": { "yaw": 0 },
    "file": "models/11111.obj"
  }
}

8.2. Внутренние структуры

Камера:

{
  target: [x, y, z],
  distance: number,
  yaw: number,
  pitch: number
}

Модель:

{
  positions: Float32Array,  // x, y, z для каждой вершины
  normals: Float32Array,    // nx, ny, nz для каждой вершины
  colors: Float32Array,     // r, g, b для каждой вершины
  uvs: Float32Array         // u, v для каждой вершины
}

9. Алгоритмы

9.1. Загрузка OBJ модели

  1. Загрузка текстового файла через fetch
  2. Парсинг строк (вершины, нормали, грани)
  3. Определение системы индексации
  4. Вычисление границ модели
  5. Центрирование и масштабирование
  6. Создание треугольников из граней
  7. Вычисление нормалей для треугольников

9.2. Нормализация высоты

  1. Вычисление высоты каждой модели после загрузки
  2. Поиск максимальной высоты
  3. Для каждой модели: вычисление коэффициента масштабирования
  4. Масштабирование всех вершин по Y относительно центра
  5. Обновление базовых позиций и центров
  6. Применение трансформации

9.3. Рендеринг

  1. Обновление движения камеры (если нажаты клавиши)
  2. Обновление вращения моделей (если нажаты Q/E)
  3. Очистка буферов
  4. Вычисление матриц проекции и вида
  5. Установка uniform переменных (свет, текстуры)
  6. Отрисовка пола и сетки
  7. Отрисовка всех моделей
  8. Запрос следующего кадра через requestAnimationFrame

10. Константы и настройки

  • PLAN_SIZE: 1100 (базовый размер плана, увеличен в 5 раз)
  • GRID_CELL_SIZE: 100 (размер ячейки сетки)
  • POSITION_STEP: PLAN_SIZE * 0.01 (шаг перемещения)
  • ROTATION_STEP: Math.PI / 36 (5 градусов)
  • Дальность обзора: 10000 единиц
  • Расстояние камеры: 60-2000 единиц

11. Обработка ошибок

Приложение включает обработку ошибок:

  • Проверка доступности WebGL контекста
  • Обработка ошибок парсинга OBJ
  • Try-catch блоки для предотвращения падений
  • Перехват глобальных ошибок для предотвращения перезагрузки страницы

12. Производительность

Оптимизации

  • Использование VAO (Vertex Array Objects)
  • Статические буферы для неизменяемых данных
  • Обновление GPU буферов только при изменении модели
  • Проверка валидности данных перед отрисовкой

13. Использование

Запуск

  1. Установить Python 3
  2. Запустить сервер: python start_server.py
  3. Открыть браузер: http://localhost:3000

Рабочий процесс

  1. Модели загружаются автоматически при открытии
  2. Выбрать модель клавишами 1-7
  3. Включить Position Mode для позиционирования
  4. Переместить и повернуть модель
  5. Экспортировать позиции для сохранения
  6. При следующем открытии позиции загрузятся автоматически

14. Технический стек

  • WebGL — 3D рендеринг
  • Vanilla JavaScript — без фреймворков
  • Python HTTP Server — для разработки
  • OBJ формат — для 3D моделей
  • JSON — для сохранения позиций

15. Заключение

Приложение представляет собой полнофункциональный 3D редактор для позиционирования моделей зданий на плане. Основные возможности включают интерактивное управление камерой, точное позиционирование моделей, автоматическую нормализацию высоты и экспорт/импорт позиций.
