# 3D Floor Plan Viewer (WebGL)

Веб-приложение для просмотра и позиционирования 3D моделей зданий на плане этажа.

## Возможности

- Загрузка и отображение нескольких 3D моделей (OBJ формат)
- Интерактивное позиционирование моделей на плане
- Вращение моделей
- Экспорт позиций моделей в JSON
- Управление камерой (полёт, зум, вращение)
- Инженерная сетка для ориентации в размерах
- Автоматическая нормализация высоты всех моделей

## Управление

### Камера
- **Мышь** - перетаскивание для вращения камеры
- **Колёсико** - приближение/отдаление
- **Стрелки/WASD** - движение камеры по полю
- **Space/Shift** - движение камеры вверх/вниз
- **R** - сброс позиции камеры

### Модели
- **1-7** - выбор модели для позиционирования
- **Q/E** - вращение выбранной модели
- **Position Mode** - включить/выключить режим позиционирования
- В Position Mode:
  - **Стрелки** - перемещение модели
  - **Q/E** - вращение модели
  - **PageUp/PageDown** - движение модели вверх/вниз

## Установка и запуск

1. Установите Python 3
2. Запустите сервер:
   ```bash
   python start_server.py
   ```
   или
   ```bash
   start-server.bat
   ```
3. Откройте браузер: http://localhost:3000

## Структура проекта

- `fa-main/index.html` - главная страница
- `fa-main/main.js` - основной код приложения
- `fa-main/styles.css` - стили
- `fa-main/models/` - папка с OBJ моделями
- `fa-main/model_positions.json` - файл с позициями моделей

## Технологии

- WebGL для 3D рендеринга
- Vanilla JavaScript (без фреймворков)
- Python HTTP Server для разработки
